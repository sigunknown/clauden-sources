API Clauden

Редакция от 15 ноября 2026 г.

Один шлюз для Anthropic- и OpenAI-совместимых клиентов: Claude Code, OpenCode, Codex, Cursor, SDK и обычный curl. Ключ берётся в Clauden и работает с вашим тарифом.

Быстрый старт

  1. Получите ключ. Откройте Clauden → Настройки → API-ключ и нажмите «Получить ключ». Ключ показывается один раз. Он доступен на тарифах Pro, Max и Ultra.
  2. Сохраните его в переменную окружения. Не вставляйте ключ в исходники и не публикуйте его.
    Linux / macOS
    export CLAUDEN_API_KEY="sk-cld-ushw-..."
    Windows PowerShell
    setx CLAUDEN_API_KEY "sk-cld-ushw-..."

    После setx закройте и откройте терминал заново — старая сессия переменную не увидит.

  3. Проверьте подключение. Запрос списка моделей должен вернуть JSON с массивом data.
    Проверка ключа
    curl -s https://clauden.best/v1/models \
  -H "x-api-key: $CLAUDEN_API_KEY"
Базовый адрес зависит от клиента. Claude Code и Anthropic SDK используют https://clauden.best — они сами добавляют /v1/messages. OpenCode, OpenAI SDK, Codex и Cursor используют https://clauden.best/v1 — они добавляют только /messages, /chat/completions или /responses.

Ключ и авторизация

Ключи Clauden начинаются с sk-cld-ushw-. Ключ привязан к вашему аккаунту и тарифу: запросы расходуют лимиты тарифа, а после понижения тарифа ключ получает новые ограничения.

Заголовки

Поддерживаются оба варианта — достаточно одного:

ЗаголовокФорматГде используется
x-api-keysk-cld-ushw-…Anthropic SDK, Claude Code, Anthropic-совместимые клиенты
AuthorizationBearer sk-cld-ushw-…OpenAI SDK, Codex, OpenCode, большинство OpenAI-совместимых клиентов

Выпуск и отзыв

  • Ключ выпускается в веб-интерфейсе или приложении: Настройки → API-ключ.
  • Полный ключ показывается один раз. Дальше в списке видна только маска вида sk-cld-ushw-AbCd…wxyz.
  • Отозвать ключ можно там же. После отзыва запросы с ним получают 401.
  • Количество одновременных ключей зависит от тарифа: Pro — 3, Max — 5, Ultra — 8. Кнопка «Сбросить ключ» выпускает новый и отзывает старые.
Ключ — это пароль от вашего лимита. Не передавайте его третьим лицам и не используйте в браузерном JavaScript. Если ключ попал в лог, скриншот или репозиторий — отзовите его и выпустите новый.

Установка приложений

Веб-версия открывается сразу в браузере. Приложения для Windows, macOS, Linux и Android, а также Clauden Code ставятся отдельно и используют тот же аккаунт Clauden.

Windows

  1. Скачайте установщик Clauden-latest.exe.
  2. Запустите его и подтвердите установку. Windows SmartScreen может предупредить, потому что подпись кода не настроена — выберите «Подробнее» → «Выполнить в любом случае».
  3. Откройте Clauden и войдите в тот же аккаунт. Обновления приложение скачивает и ставит само.

macOS

Нужна macOS 13 Ventura или новее. Откройте меню Apple → «Об этом Mac» и посмотрите процессор. Для Apple Silicon (M1–M4) скачайте Clauden-latest-mac-arm64.zip, для Intel — Clauden-latest-mac-x64.zip.

  1. Распакуйте архив и перетащите Clauden.app в папку «Программы».
  2. Запустите Clauden. macOS предупредит, что приложение скачано из интернета и не подписано Apple.
  3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз и нажмите «Открыть всё равно» для Clauden. На старых версиях macOS можно нажать на приложение правой кнопкой → «Открыть».
  4. Войдите в аккаунт Clauden — чаты, проекты и подписка будут те же.
Подпись Apple пока не настроена. Поэтому первый запуск требует подтверждения. Если macOS пишет, что приложение повреждено, выполните в Терминале xattr -dr com.apple.quarantine /Applications/Clauden.app и запустите снова.

Обновления macOS-сборки пока ставятся вручную: скачайте новый архив и замените приложение в «Программах». Настройки и чаты сохранятся.

Android

  1. Скачайте APK-файл.
  2. Разрешите установку из браузера или файлового менеджера, если Android попросит.
  3. Войдите в аккаунт Clauden — чаты, проекты и подписка будут те же.

Если установка не получается, напишите в Telegram-канал или в поддержку @GwardenSup.

Linux

Для большинства дистрибутивов подойдёт AppImage — один файл, который не требует установки. Скачайте Clauden-latest.AppImage:

AppImage
chmod +x Clauden-latest.AppImage
./Clauden-latest.AppImage

Если в системе нет libfuse2, запустите с флагом --appimage-extract-and-run.

Для Debian/Ubuntu есть пакет .deb — Clauden-latest.deb:

DEB
sudo apt install ./Clauden-latest.deb

Портативная версия без установки — Clauden-latest-linux.tar.gz.

Clauden Code: приложение для Windows

Установщик Clauden Code — дерево файлов, редактор с подсветкой, диффы с коммитом, чат агента и локальный терминал в одном окне. Сессия открывается прямо на этом компьютере: агент правит файлы на диске.

Clauden Code: терминал

Для CLI нужен Node.js 18+. Скачайте clauden-code-0.1.1.tgz и установите его:

npm
npm install -g ./clauden-code-0.1.1.tgz
clauden login

Или без npm, через install.sh. Команда /remote-control внутри сессии отдаёт живую сессию по ссылке.

OpenCode

OpenCode подключается к Clauden как Anthropic-совместимый провайдер. Модели, инструменты и потоковые ответы работают через /v1/messages.

Нужно OpenCode 2.x и активный тариф Clauden (Pro, Max или Ultra). Если у вас 1.x, выполните opencode upgrade.

1. Установите и проверьте OpenCode

Установка
curl -fsSL https://opencode.ai/install | bash
opencode --version

Другие способы установки — в документации OpenCode: opencode.ai/docs.

2. Задайте ключ Clauden

OpenCode читает ключ из переменной окружения. Добавьте её в профиль shell или задайте в текущей сессии:

Linux / macOS
echo 'export CLAUDEN_API_KEY="sk-cld-ushw-..."' >> ~/.bashrc
source ~/.bashrc
Windows PowerShell
setx CLAUDEN_API_KEY "sk-cld-ushw-..."

3. Добавьте провайдера в конфиг

Откройте глобальный конфиг OpenCode:

  • Linux / macOS: ~/.config/opencode/opencode.jsonc
  • Windows: %USERPROFILE%\.config\opencode\opencode.jsonc

Добавьте провайдера clauden и выберите модель по умолчанию:

opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "clauden/claude-sonnet-5-5",
  "providers": {
    "clauden": {
      "name": "Clauden",
      "env": ["CLAUDEN_API_KEY"],
      "package": "@opencode/ai/providers/anthropic-compatible",
      "settings": {
        "baseURL": "https://clauden.best/v1"
      },
      "models": {
        "claude-fable-5-2": { "name": "Claude Fable 5.2" },
        "claude-opus-5-5": { "name": "Claude Opus 5.5" },
        "claude-sonnet-5-5": { "name": "Claude Sonnet 5.5" },
        "claude-haiku-5-5": { "name": "Claude Haiku 5.5" }
      }
    }
  }
}
Обратите внимание на baseURL. OpenCode добавляет к адресу только /messages или /chat/completions, поэтому в конфиге указывается https://clauden.best/v1. В Claude Code и Anthropic SDK — наоборот, https://clauden.best без /v1, потому что они добавляют /v1/messages сами.

4. Проверьте модели и запустите

Проверка
opencode models | grep clauden
opencode run -m clauden/claude-sonnet-5-5 "Напиши функцию на Python для чтения CSV"

В интерактивном интерфейсе нажмите /models и выберите модель из провайдера Clauden. Конфиг перечитывается автоматически — перезапускать OpenCode не нужно.

Вариант с OpenAI-совместимым провайдером

Если клиент или плагин требует OpenAI Chat Completions, используйте тот же ключ и другой пакет:

opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "clauden/claude-sonnet-5-5",
  "providers": {
    "clauden": {
      "name": "Clauden",
      "env": ["CLAUDEN_API_KEY"],
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://clauden.best/v1"
      },
      "models": {
        "claude-sonnet-5-5": { "name": "Claude Sonnet 5.5" },
        "claude-opus-5-5": { "name": "Claude Opus 5.5" }
      }
    }
  }
}

Для OpenAI-совместимого пакета baseURL всегда содержит /v1.

Если OpenCode не видит провайдера

  • Проверьте, что ключ виден процессу: echo $CLAUDEN_API_KEY (Linux/macOS) или $env:CLAUDEN_API_KEY (PowerShell).
  • Проверьте синтаксис JSONC: лишняя запятая ломает весь конфиг.
  • Запустите opencode models — в списке должны быть модели clauden/….
  • Если модели видны, но запрос возвращает 401, добавьте в settings провайдера строку "apiKey": "{env:CLAUDEN_API_KEY}".
  • Проверьте ключ отдельно через curl из раздела Примеры запросов.

Claude Code

Claude Code — терминальный клиент Anthropic. Clauden подключается к нему как Anthropic-совместимый API. Нужны Node.js 18+, установленный Claude Code и ключ Clauden.

1. Установите Claude Code

npm
npm install -g @anthropic-ai/claude-code
claude --version

Если Claude Code уже установлен, обновите его: npm update -g @anthropic-ai/claude-code.

2. Получите ключ Clauden

Откройте Настройки → API-ключ и нажмите «Получить ключ». Он показывается один раз и начинается с sk-cld-ushw-. Ключ работает на тарифах Pro, Max и Ultra.

3. Задайте адрес и токен

Для Claude Code базовый адрес указывается без /v1 — клиент сам добавляет /v1/messages.

Linux / macOS — на эту сессию
export ANTHROPIC_BASE_URL="https://clauden.best"
export ANTHROPIC_AUTH_TOKEN="sk-cld-ushw-..."
claude

Чтобы не вводить каждый раз, добавьте эти строки в ~/.zshrc (macOS) или ~/.bashrc (Linux) и выполните source ~/.zshrc или source ~/.bashrc.

Windows PowerShell
$env:ANTHROPIC_BASE_URL = "https://clauden.best"
$env:ANTHROPIC_AUTH_TOKEN = "sk-cld-ushw-..."
claude

Для постоянных переменных в Windows используйте setx ANTHROPIC_BASE_URL "https://clauden.best" и setx ANTHROPIC_AUTH_TOKEN "sk-cld-ushw-...", затем закройте и откройте терминал заново.

Используйте ANTHROPIC_AUTH_TOKEN, а не ANTHROPIC_API_KEY. Clauden принимает оба варианта, но токен не выглядит как официальный ключ Anthropic и реже конфликтует с уже сохранённым входом в Claude Code.

4. Проверьте подключение

Проверка
claude --model claude-sonnet-5-5 "Ответь одним словом: работает"

Внутри интерактивной сессии команда /status показывает выбранную модель и адрес API, а /model позволяет сменить модель.

5. Постоянные настройки через settings.json

Можно прописать адрес, токен и модель в файле настроек Claude Code. Путь: ~/.claude/settings.json на macOS/Linux или %USERPROFILE%\.claude\settings.json на Windows.

settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://clauden.best",
    "ANTHROPIC_AUTH_TOKEN": "sk-cld-ushw-...",
    "ANTHROPIC_MODEL": "claude-sonnet-5-5",
    "CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK": "1"
  }
}

Если файл уже существует, добавьте поля внутрь существующего объекта env, а не заменяйте весь файл. На Windows пути в JSON записываются с двойными обратными слэшами.

Если не работает

  • 401 Invalid API key — ключ скопирован не полностью, отозван или в переменной остались кавычки/пробелы. Выпустите новый ключ и проверьте echo $ANTHROPIC_AUTH_TOKEN (PowerShell: $env:ANTHROPIC_AUTH_TOKEN).
  • 403 subscription_required — нет активного тарифа Clauden или он истёк. Проверьте тариф в настройках аккаунта.
  • 404 model — имя модели не совпало. Запросите список через GET /v1/models и используйте точный ID, например claude-sonnet-5-5.
  • Команда claude не найдена — npm установил пакет не в PATH. Проверьте npm prefix -g и добавьте каталог bin в PATH.
  • Долгие ответы обрываются — оставьте CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK=1, как в примере выше.

Codex

Codex ходит в OpenAI Responses API. Добавьте провайдера в ~/.codex/config.toml:

config.toml
model = "claude-sonnet-5-5"
model_provider = "clauden"

[model_providers.clauden]
name = "Clauden"
base_url = "https://clauden.best/v1"
env_key = "CLAUDEN_API_KEY"
wire_api = "responses"

Ключ должен быть в переменной CLAUDEN_API_KEY. После изменения конфига перезапустите Codex.

Cursor

Cursor подключается как OpenAI-совместимый провайдер:

  1. Откройте Settings → Models → API Keys.
  2. Включите переопределение OpenAI Base URL и укажите https://clauden.best/v1.
  3. В поле OpenAI API Key вставьте ключ sk-cld-ushw-….
  4. Добавьте модель вручную: claude-sonnet-5-5 или claude-opus-5-5.

Названия пунктов меню могут отличаться между версиями Cursor. Главное — base URL с /v1 и ключ Clauden.

Примеры запросов

Anthropic Messages

curl
curl -s https://clauden.best/v1/messages \
  -H "x-api-key: $CLAUDEN_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-5-5",
    "max_tokens": 256,
    "messages": [
      { "role": "user", "content": "Привет! Кто ты?" }
    ]
  }'

Поле max_tokens обязательно. Для потокового ответа добавьте "stream": true.

OpenAI Chat Completions

curl
curl -s https://clauden.best/v1/chat/completions \
  -H "Authorization: Bearer $CLAUDEN_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-5-5",
    "messages": [
      { "role": "user", "content": "Привет! Кто ты?" }
    ]
  }'

OpenAI Responses

curl
curl -s https://clauden.best/v1/responses \
  -H "Authorization: Bearer $CLAUDEN_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-sonnet-5-5",
    "input": "Привет! Кто ты?"
  }'

Python SDK

Anthropic SDK
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-cld-ushw-...",
    base_url="https://clauden.best",
)

message = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "Привет!"}],
)
print(message.content[0].text)
OpenAI SDK
from openai import OpenAI

client = OpenAI(
    api_key="sk-cld-ushw-...",
    base_url="https://clauden.best/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5-5",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(response.choices[0].message.content)

Модели

Актуальный список всегда доступен через GET /v1/models. Идентификаторы моделей чувствительны к регистру и дефисам: используйте ровно те значения, которые вернул сервер.

ID моделиНазваниеДоступ
claude-fable-5-2Claude Fable 5.2Max, Ultra
claude-opus-5-5Claude Opus 5.5Pro, Max, Ultra
claude-sonnet-5-5Claude Sonnet 5.5Pro, Max, Ultra
claude-haiku-5-5Claude Haiku 5.5Pro, Max, Ultra

В ответе также могут быть доступны модели предыдущих поколений: claude-fable-5-1, claude-fable-5, claude-opus-5, claude-opus-4-8, claude-sonnet-5. Для новых интеграций выбирайте модели из таблицы выше.

Эндпоинты

МетодПутьФормат
GET/v1/modelsСписок моделей
POST/v1/messagesAnthropic Messages, JSON или SSE
POST/v1/messages/count_tokensПодсчёт токенов Anthropic
POST/v1/chat/completionsOpenAI Chat Completions, JSON или SSE
POST/v1/responsesOpenAI Responses, JSON или SSE
GET/v1/plansПубличный список тарифов, без ключа

Потоковые ответы

Во всех трёх чат-эндпоинтах поддерживается stream: true:

  • /v1/messages отдаёт Anthropic SSE-события (message_start, content_block_delta, message_stop).
  • /v1/chat/completions отдаёт OpenAI-чанки и завершается строкой [DONE].
  • /v1/responses отдаёт события Responses API.

Дополнительные поля Clauden

Необязательные поля для интеграций, которым нужен контекст проекта или память:

ПолеЧто делает
clauden_projectТекст с инструкциями и знаниями проекта, добавляется в системный промпт.
clauden_contextКороткий контекст или заметки к запросу.
clauden_systemДополнительный системный промпт.
clauden_memoryfalse отключает автоматическую память аккаунта.

Ошибки и лимиты

Anthropic-эндпоинты возвращают ошибки в формате Anthropic, OpenAI-эндпоинты — в формате OpenAI.

КодТипЧто значит
400invalid_request_errorНет обязательного поля, например max_tokens, или неверный JSON.
401authentication_errorКлюч не передан, отозван или неверен.
403permission_error / subscription_requiredНет активного тарифа или модель недоступна на вашем тарифе.
404not_found_errorНеизвестная модель или путь. Проверьте ID через /v1/models.
429rate_limit_errorДневной или тарифный лимит исчерпан, либо слишком много одновременных запросов.
503overloaded_error / server_errorВременная недоступность или техработы. Повторите позже.

В ответе 429 может быть поле resets_at — время, когда лимит сбросится. Лимиты зависят от тарифа и общие с приложением Clauden: запросы через API расходуют тот же лимит, что и чаты в интерфейсе.

Безопасность

  • Храните ключ в переменной окружения или менеджере секретов, а не в коде и не в публичном репозитории.
  • Для каждого устройства или приложения используйте отдельный ключ — так проще отозвать доступ, не ломая остальные интеграции.
  • Не используйте ключ в браузерном JavaScript: любой посетитель страницы сможет его забрать.
  • Если ключ утёк, отзовите его в Настройках → API-ключ и выпустите новый. Старый сразу перестанет работать.
  • Clauden не просит пароль от Anthropic для API-доступа. Для ключа нужен только аккаунт и тариф Clauden.

Вопросы

Почему 401 Invalid API key?

Ключ не передан, скопирован не полностью или уже отозван. Проверьте заголовок x-api-key или Authorization: Bearer … и убедитесь, что в переменной нет кавычек и пробелов.

Почему 404 model?

Имя модели не совпало с каталогом. Запросите GET /v1/models и используйте точный id, например claude-sonnet-5-5, а не claude-sonnet-5.5.

Почему 403 subscription_required?

API-ключи и запросы через шлюз доступны на платных тарифах Clauden. Проверьте, что тариф активен и не истёк. Подписка Anthropic или тариф, выданный вручную, ключ не открывает.

Можно ли использовать ключ в OpenAI SDK?

Да. Укажите base_url="https://clauden.best/v1" и ключ Clauden. Работают /v1/chat/completions и /v1/responses.

Где взять ключ, если я оплатил тариф?

Войдите в Clauden под тем же аккаунтом, которым оплачивали тариф, и откройте Настройки → API-ключ. Если раздела нет или ключ не выпускается, напишите в поддержку.
