## Визуал: как открыть копию

```powershell
python get-fonts.py
python serve.py
```

`get-fonts.py` нужен один раз. Без него сайт тоже откроется, но со шрифтами по умолчанию.

Затем откройте `http://localhost:8766`. Адреса вида `/pricing` сервер отдаёт из `pricing.html`, как на настоящем сайте.

Копия совпадает с живым сайтом визуально: в `screenshots/` пары `*-live.jpg` и `*-local.jpg` одинаковые. Маскот на главной анимирован, поэтому его поза на снимках может отличаться.

Чего копия не умеет: запросы к их API (`/v1/...`) возвращают 404, потому что бэкенда Clauden в папке нет. Вход, чаты и оплата не работают. Интерфейс чата после входа рисуется тем же `js/app.bundle.js` и `css/app.css`, которые лежат в копии, но без ответов сервера его не открыть.

Шрифты `anthropic_sans`, `anthropic_serif` и их курсивы Clauden раздаёт со своего сайта. Судя по названиям, это фирменные шрифты Anthropic, поэтому в репозитории их нет. Их хэши записаны в `hashes.txt`, а `get-fonts.py` скачивает те же файлы с clauden.best.

## Чего в папке нет

- **Сама программа-оболочка.** `Clauden.exe` — это стандартный Electron 45.2.2 без подписи (фьюзы по умолчанию). Чтобы собрать программу заново, нужно упаковать `app/` в `app.asar` и положить рядом `resources/xray/`. Побайтово архив может отличаться порядком файлов, поэтому сверяйте содержимое файлов, а не хэш `app.asar`.
- **`xray.exe`** (SHA-256 `d5b558191cccb1e92a5772b68b8cab67717b26f634b0f15153215f65ae982a7e`) и `elevate.exe` (`9b1fbf0c…`): сторонние бинарники, `xray` соответствует официальному Xray-core.
- **Установщик `Clauden-latest.exe`.** Лежит в «Загрузках», его хэш есть в `hashes.txt`, SHA-512 совпадает с `server/latest.yml`. Значит, это та же сборка, которую сервер раздаёт всем.
- **Android-версия `app/latest.apk`.** Её по ссылке со страницы случайно скачал сборщик. Я её удалил, хэш оставлен в `hashes.txt`.
- **Бэкенд clauden.best:** код сервера снаружи недоступен.

## Где в коде каждое утверждение

Пути указаны относительно `app/src/main/`.

### Главное окно — это сайт с доступом к программе
- `main.js:15` — адрес окна `https://clauden.best`, `main.js:396` — его загрузка.
- `preload.js:49` — в страницу добавляется объект `window.claudenDesktop` со всеми функциями.
- `ipc.js:9` — единственная проверка: запрос пришёл с clauden.best (или с localhost и `file://`).

### Чтение и запись любых файлов
- `ipc.js:19` — `safeLocalPath` проверяет путь относительно `root`, а `root` передаёт сама страница.
- `ipc.js:185` — `local:read`, чтение до 400 КБ.
- `ipc.js:198` — `local:write`, запись до 500 КБ.

### Утечка сохранённых API-ключей
- `custom-api.js:20` — комментарий «Renderer никогда не получает сохранённый ключ обратно».
- `custom-api.js:288`, `custom-api.js:298` — `test()` берёт сохранённый ключ по `id`.
- `custom-api.js:303` — отправляет его на `${base}/models`, где `base` пришёл со страницы.
- `custom-api.js:42` — `normalizeBaseUrl` не ограничивает хост.
- `ipc.js:447` — `customApi:test` открыт странице.

### Управление аккаунтом claude.ai
- `ipc.js:337`, `ipc.js:347` — список и содержимое чатов (`claude:import/list`, `claude:import/one`).
- `ipc.js:358` — отправка сообщений от имени пользователя (`claude:start`).
- `ipc.js:321` — скачивание файлов (`claude:download`).
- Автосинхронизация списка чатов при запуске: в `site/js/app.bundle.unescaped.js` искать `mt.importList({offset:r,limit:100})`.

### Импорт входа из Claude Desktop
- `ipc.js:306` — `claude:desktop/import`.
- `claude-session.js:163` — `importFromDesktop`.
- `claude-desktop.js:126` — расшифровка ключа через DPAPI (PowerShell), `claude-desktop.js:379` — чтение cookie claude.ai, `claude-desktop.js:111` — закрытие Claude через `taskkill`.

### Автообновление без подписи
- `updater.js:19` — источник обновлений clauden.best.
- `updater.js:42` — комментарий «Подпись кода не настроена».
- `updater.js:84` — установка при выходе из программы.
- `main.js:498` — проверка каждые 6 часов.

### Ключей и переключения при бане нет
- `claude-client.js:250` — `httpError`: на 403 текст «смените VPN» (`:254`), на 429 ошибка с таймером (`:260`). Другой реакции на бан в коде нет.
- Поиск форматов ключей (`sk-ant-`, `sk-`, `sk-or-`, `AIza`, `AKIA`, `ghp_`, JWT, приватные ключи) по `app/src/` и `site/` ничего не находит.
- Обещания с сайта: в `site/js/app.bundle.unescaped.js` искать `резервный запас ключей` (4 места) и `выданный аккаунт Claude`.

### Прокси: пять «стран» на одном адресе
- `proxy.js:26`–`32` — пять зашитых узлов, все `188.40.190.90`, порты 8413–8417.
- `proxy.js:247` — тот же список запрашивается с сервера, `server/proxy-nodes.json` показывает тот же адрес.
- `proxy.js:334`–`337` — комментарий: claude.ai пойдёт не «с общего выхода Clauden, на который Anthropic чаще всего и отвечает 429».
- `main.js:486` — комментарий «общий встроенный узел только подменяет адрес и ловит 429 Anthropic».
- `proxy.js:69` — прокси не включается, если пользователь выходит в интернет не из России.
- `server/rdap-188.40.190.90.json` — диапазон `188.40.190.88–95`, страна DE, abuse-контакт Hetzner Online GmbH.
- `proxy.js:393` — прокси применяется и к сессии claude.ai (`ses.setProxy`).
- `ipc.js:534`, `ipc.js:549` — страница может подставить свою подписку и подключить её.

## Как проверить самому
1. Установить Clauden 0.2.9 и сравнить SHA-256 файла `resources\app.asar` со значением из `hashes.txt`.
2. Распаковать `app.asar` любой утилитой для asar (например `npx @electron/asar extract app.asar out`) и сравнить файлы с `app/`.
3. Сравнить файлы из `site/` с тем, что сейчас отдаёт clauden.best, по `site/mirror-log.tsv` и `hashes.txt`. Если сайт успели поменять, хэши разойдутся.
4. Открыть `https://clauden.best/v1/proxy/nodes` и убедиться, что все узлы указывают на один адрес.
